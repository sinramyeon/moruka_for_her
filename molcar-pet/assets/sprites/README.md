# Sprite Assets

Place your custom sprites here. Required files (6 total):

| File | Description |
|------|-------------|
| `classic_baby.png` | Classic species, baby stage |
| `classic_teen.png` | Classic species, teen stage |
| `classic_adult.png` | Classic species, adult stage |
| `shiny_baby.png` | Shiny species, baby stage |
| `shiny_teen.png` | Shiny species, teen stage |
| `shiny_adult.png` | Shiny species, adult stage |

Recommended size: **180 x 130 px** (or multiples thereof for retina).

Until these files are added, the game renders SVG placeholder molcars automatically.
