# 모루카 키우기 🚗

기니피그 자동차(모루카)를 돌보는 다마고치형 웹게임.

## 실행 방법

ES 모듈은 `file://`에서 동작하지 않으므로 로컬 서버가 필요합니다.

```bash
cd molcar-pet
npx serve .
```

브라우저에서 `http://localhost:3000` 으로 접속하세요.

## 게임 플레이

- **스탯 4종** (배고픔/행복/청결/에너지)이 시간이 지남에 따라 줄어듭니다.
- 하단 **액션 버튼**으로 모루카를 돌봐주세요.
- 모루카가 **말풍선(💭)** 으로 원하는 것을 표현하면, 해당 액션을 해주세요 → 코인 + 케어 보상!
- 5분 내에 들어주지 않으면 케어 점수가 깎입니다.
- **성장**: 아기(0분) → 청소년(30분) → 성체(120분)
- **진화**: 성체 진입 시 케어 점수 60 이상이면 🌟 **shiny**, 미만이면 **classic**.
- 새로고침해도 localStorage에 자동 저장됩니다.

## 스프라이트 교체

`assets/sprites/` 에 아래 6장을 넣으면 자동 교체됩니다:

| 파일명 | 설명 |
|--------|------|
| `classic_baby.png` | 클래식 아기 |
| `classic_teen.png` | 클래식 청소년 |
| `classic_adult.png` | 클래식 성체 |
| `shiny_baby.png` | 샤이니 아기 |
| `shiny_teen.png` | 샤이니 청소년 |
| `shiny_adult.png` | 샤이니 성체 |

권장 크기: 180 x 130 px
